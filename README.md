# 📚 Online Book Store – Manual Testing Project

## Software Quality Assurance (Manual + Automation)

---

## 📖 Project Overview

This repository contains the complete **Manual Testing documentation** for the **Online Book Store Enterprise Platform**, developed as part of the **Software Quality Assurance (SQA)** assignment.

The objective of this project is to demonstrate professional manual testing practices, including test planning, test case design, test execution, reporting, and test management using **Testworthy**.

---

# 🎯 Project Objectives

- Create a High-Level Test Plan
- Design comprehensive manual test cases
- Organize test suites and sections in Testworthy
- Execute test cases through a Test Run
- Generate Test Execution Reports
- Export Test Cases
- Document testing activities following industry best practices

---

# 🛒 Application Under Test

**Online Book Store Enterprise Platform**

The application allows users to:

- Register and authenticate
- Browse book catalog
- Search books
- View book details
- Add books to shopping cart
- Complete checkout
- Make online payments
- View order history
- Manage user profile
